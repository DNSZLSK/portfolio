# Textures

## paper.jpg

Dépose ici une photo d'une vraie pochette de vinyle, nommée `paper.jpg`.
Elle est reprise automatiquement par `.paper` dans `css/base.css` et se fond
dans le carton en `soft-light`. Tant que le fichier est absent, la couche ne
s'affiche pas et la texture calculée reste seule.

Prise de vue :

- pochette à plat, près d'une fenêtre, lumière diffuse, pas de soleil direct
- téléphone bien parallèle à la pochette, pas d'angle
- cadrer une zone vierge du carton, pas le visuel imprimé
- le carton remplit tout le cadre, aucune ombre portée

Après :

- recadrer en carré, viser 1600 px de côté
- compresser à 150 Ko maximum, c'est une texture de fond, pas une photo
- pas d'image sous licence (iStock, Getty, Shutterstock)
